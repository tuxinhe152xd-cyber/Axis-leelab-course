# 學員複製貼上卡：上午情境（每日新聞摘要）

用法：Dashboard **開新對話**，先貼「第 1 步」，之後 AI 問一題，你從「第 2 步」挑對應的句子貼一句。AI 問的順序和字句會略有不同，意思對得上就用該句；問了卡上沒有的事，就答「不知道」。

> 狀態：這些句子 2026-11-11 用腳本送進 OpenClaw 跑通（訪談 → 藍圖 → 建置 → 現場跑一次 → AI 建立停用的排程）。**真人在 Dashboard 貼還沒驗證。**

**開始前**：不需要改任何設定，排程與讀網頁已經預設開啟。

## 你扮演的人
你是農業部某業務單位的承辦人，每天要替科長整理新聞（內容虛構）。每天早上八點到九點自己上網看幾個網站，整理成農業、食品、經濟、氣候、政策五類，用 Word 存檔再 Email 寄出。上週漏看一則政策新聞，科長開會被問到。

## 第 1 步：開場（整句貼）
```text
$workflow-decompose 我想用 AI 幫忙處理工作，請開始。
```

## 第 2 步：訪談回答（AI 問到哪個主題，就貼哪一句）

**你是誰**
```text
我是農業部某業務單位的承辦人，每天要替科長整理新聞。
```

**做什麼、給誰**
```text
我每天產出一頁新聞摘要給科長，也偶爾轉給三位同事。
```

**現在怎麼運作**
```text
每天早上八點到九點，我自己上網看幾個新聞網站和農業部網站，複製重點到 Word，分成農業、食品、經濟、氣候、政策五類。
```

**最近一次出事、損失**
```text
上週有一則政策新聞我漏看了，科長在會議上被問到，我才補，大概多花了半小時，這是估的。
```

**限制（預算、設備、資料）**
```text
只能用公開網站，不能用內部資料。公務電腦不能裝程式，但可以開網頁。摘要不能出現沒查證的數字。沒有預算。
```

**它整理後問「以上正確嗎」（每個階段結束都會問，都回「對。」；第一次可補這句）**
```text
對。每天看大概五個網站、十到十五則新聞。漏看大概每個月一兩次，估的。
```

**誰會碰到這份摘要**
```text
科長和三位同事看摘要，我是唯一負責整理的人。
```

**在哪裡、用什麼裝置**
```text
在辦公室，用公務電腦。摘要用 Word 存檔，再用 Email 寄出。
```

**一天多少、花多久**
```text
每天一份。整理大概花一個小時，這是估的。
```

**希望變成什麼樣子**
```text
希望每天早上八點前就有一份分好五類的摘要，我只要檢查再寄出。
```

**更大的目的**
```text
就是不要再漏看重要的政策新聞，也不用每天花一個小時從頭整理。
```

**「重要」指什麼**
```text
因為科長開會前要掌握最新政策，不能被問倒。這是我最在意的。重要的政策新聞，主要是跟農業部、農產品價格、食品安全、補助、氣候災害有關的。
```

**怎麼做到**
```text
我想像是有一個東西每天早上自動去看那幾個網站，整理成五類。但怎麼做我不知道。
```

**為什麼重要**
```text
因為早上我沒有時間從頭看完，有東西先整理好，我才不會漏看，也才來得及檢查。
```

**說一句可以測的話（故意先說不可測的）**
```text
我說「幫我整理好今天的新聞」，它要把新聞整理好。
```

**被退回後，說可以測的版本**
```text
我說「整理今天的農業新聞」，它要回一份分成農業、食品、經濟、氣候、政策五類的摘要，每則有標題、一句重點和來源網址，而且不能有沒有出處的數字。
```

**怎麼知道沒漏**
```text
推論對。我沒辦法百分之百知道，所以摘要最後要列出它今天看了哪幾個網站、各抓到幾則，我可以對照有沒有少。
```

**內容格式一樣嗎**
```text
不一樣。每個網站的標題和內容寫法都不同，要判斷是哪一類，分類要看意思。但摘要的格式是固定的。
```

**資料在哪**
```text
都在公開網站上，網頁就能看到，不用登入。
```

**錯了的後果**
```text
如果漏掉重要政策或寫錯數字，科長開會被問倒，影響我的專業信用。補救只能事後補。
```

**哪裡要人確認**
```text
我每天都會看過再寄出，這一關一定要我自己做。
```

**最後，請它整理藍圖**
```text
對。請直接整理成最後的藍圖。
```

每個階段（A、B、C、D、E）結束 AI 都會複述並問「以上正確嗎」，回：
```text
對。
```

## 第 3 步：建置（藍圖出來後，同一個對話，不要開新的）

**它問「要不要接著建置？」**
```text
要，請接著幫我建置。
```

**它說判斷走路線 A，請你確認；再請你一次貼資料來源**
```text
1. 農業部「農業新聞」：https://www.moa.gov.tw/theme_list.php?theme=news&sub_theme=agri
2. 農業部「消費者新聞」：https://www.moa.gov.tw/theme_list.php?theme=news&sub_theme=consumer
3. 農業部「最新消息」：https://www.moa.gov.tw/theme_list.php?theme=news&sub_theme=hot
4. 農產品交易行情（農業部開放資料）：https://data.moa.gov.tw/Service/OpenData/FromM/FarmTransData.aspx?$top=30
只有這四個。
```

**它問每天幾點**
```text
每天早上七點半。
```

**它問名稱（預設 daily-news）**
```text
用預設的就好。
```

**它貼出任務指示草稿，問「這份指示可以嗎？」（它會現場跑一次）**
```text
可以，請照這份跑一次。
```

**它現場跑完一次，問「要不要把這個自動化建起來？」**（AI 會講清楚名稱、時間、內容、建成停用）
```text
好，請幫我建立這個自動化。
```

到這裡 AI 會呼叫自動化工具建立 `daily-news`（**停用**，不會自己啟用或執行）。**這張卡到此為止**（排程啟用與實際執行不在這一步）。

## 之後（你自己在 Dashboard）
1. 左側「自動化」→ 找到 `daily-news`（已暫停）。
2. 按「立即執行」，約 30～40 秒後到「執行記錄」看結果，跟剛才現場跑的對照。
3. 沒問題再打開「啟用中」。每次執行都用額度（這次 API key 上限 20 美元）。
