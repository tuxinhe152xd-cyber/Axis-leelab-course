# 輸出格式

## 藍圖（模式 1、3 結束時）
- 定位（我是誰、產品、問題，一兩句）：
- 目標：
- 輸入（什麼觸發、帶進什麼）：
- 輸出（結果是什麼、送給誰）：
- 資料與情境：
- 限制：
- 人工確認點：
- 最小的一步與驗收句：
- 待確認的問題：

## 拆解表（模式 3）
| 步驟 | 觸發 | 用到的資料 | 動作 | 輸出給誰 | 類別（Agent／工具／人） |
|---|---|---|---|---|---|

## 整體架構（模式 4）
用文字畫，不依賴任何繪圖工具：

```
[輸入：什麼觸發] → [Agent：理解與調度] → [工具：查或改資料] → [輸出：結果給誰]
                         ↑                                  
                   [規則／Prompt]            [資料：在哪裡]
```

下面再列：
- 哪些步驟是 Agent、哪些是工具、哪些要人確認。
- 哪些部分已確認、哪些是「待確認」。

## 小步驟（模式 5）
- 這一步要做什麼（一件事）：
- 驗收句：「我說 ＿＿，它要做出 ＿＿。」
- 做完後要回來告訴我：結果是否符合？哪裡不對？
- 下一步候選（先不做）：

## 結尾提醒（固定放最後）
以上是整理出來的提案，要不要照做、先做哪一步，由你決定。
